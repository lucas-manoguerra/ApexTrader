# Ejemplos de referencia

Esta carpeta queda reservada para ejemplos ejecutables que hayan sido compilados contra una versión concreta de `winit-gtk`.

No agregues snippets genéricos sin indicar:

- Versión exacta de `winit-gtk`.
- Versión de GTK-rs y `raw-window-handle`.
- Target y features utilizados.
- Comando exacto de compilación.
- Si el ejemplo requiere display, GTK del sistema o GPU.

La skill prioriza patrones arquitectónicos y verificación de versión. Un ejemplo no probado no debe presentarse como código listo para copiar.
